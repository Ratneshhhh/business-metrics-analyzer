# Business-Metrics-Analyzer

An end-to-end business analytics project built with **Power BI**, **SQL**, and **AWS cloud** to deliver dynamic insights into sales, customer behavior, and product performance. This project showcases practical data modeling, transformation, and visualization techniques suitable for real-world business decision-making.

---

## 🔍 Project Objective

To design a scalable and cloud-integrated business intelligence solution by connecting structured datasets from Excel to AWS, modeling them into a **star schema**, and building interactive dashboards in Power BI.

---

## 🧰 Tools & Technologies Used

- **Excel** – Data cleaning, formatting, and validation
- **SQL** – Data modeling using star schema and relationship setup
- **AWS S3 + Athena** – Cloud-based data storage and query access
- **Power BI** – Dashboard development and KPI reporting
- **Power Query** – Applied transformation logic and data merging
- **DAX** – Custom measures and dynamic KPI creation

---

## 📌 Project Highlights

- Connected multiple structured Excel datasets (Customers, Orders, Products, Payments, etc.)
- Cleaned and validated raw data in Excel before uploading to **AWS S3**
- Queried cloud-stored data using **Athena**, integrated directly into **Power BI**
- Modeled data into a **star schema** for efficient querying and visualization
- Built three fully interactive Power BI report pages:
  - **Sales Overview**
  - **Product Analysis**
  - **Salesperson Performance**
- Designed KPIs using DAX including:
  - Total Revenue, Total Orders, Total Customers
  - Month-over-Month (MoM) and Year-over-Year (YoY) Revenue Growth
  - Product and region-level performance metrics
- Added slicers, filters, and drill-through capabilities for user interaction
